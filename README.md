# WarmSearch-T5 校园失物招领平台 配置库

## 项目简介
本项目基于开源项目 WarmSearch 进行二次开发，新增信用认领模块和保卫处贵重物品处理模块。

## 配置库目录结构
- 01_系统需求：SRS、用例规约、补充规约、三端界面原型、界面说明
- 02_系统设计与实施：概要设计、详细设计、数据模型、SQL脚本、开源基线代码
- 03_系统集成：系统集成构建计划
- 04_系统测试：测试计划、测试用例、测试数据、测试报告
- 05_系统部署：部署包、发布说明、用户手册
- 06_系统管理：开发计划、配置管理计划、变更台账、报告模板
- 07_工具与标准：编程指南、命名规范、第三方组件清单
- 08_基线归档：各阶段基线快照、基线清单、配置审计记录

## 分支策略
- main：受保护基线分支
- develop：集成工作区
- feature/credit：信用认领模块开发分支
- feature/security：保卫处贵重物品模块开发分支

## 基线标签
- WS_BL-1：初始阶段基线（第1周）
- WS_BL-2：细化阶段基线（第3周）
